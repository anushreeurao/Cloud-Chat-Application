# Cloud Chat Application

A modern cloud-based real-time chat application built using React.js, Firebase, and Supabase that allows users to securely communicate, share files, send messages instantly, and receive real-time notifications from anywhere.

---

# Live Demo

🌐 https://cloud-chat-app-7ad88.web.app

---

# Project Overview

Cloud Chat Application is a responsive and user-friendly real-time messaging platform designed for seamless communication.

The application provides secure authentication, cloud database integration, real-time messaging, media sharing, push notifications, and a modern responsive UI for better user experience.

This project was developed to demonstrate:

- Frontend development using React.js
- Firebase Authentication
- Firebase Firestore integration
- Real-time messaging system
- Push notifications using Firebase Cloud Messaging (FCM)
- Cloud file storage using Supabase
- Responsive UI/UX design
- Cloud-based communication system

# Installation & Setup

## 1️. Clone the Repository

git clone https://github.com/anushreeurao/Cloud-Chat-Application.git

---

## 2️. Navigate to Project Directory

cd cloud-chat-app

---

## 3️. Install Dependencies

npm install

---

## 4️. Start the Development Server

npm run dev

---

# Firebase Configuration

Create a Firebase project and enable:

* Firebase Authentication
* Firestore Database
* Firebase Cloud Messaging
* Firebase Hosting

---

# Supabase Configuration

Create a Supabase project and:

* Create Storage Bucket
* Enable Public File Access
* Add Supabase Keys in `.env`
